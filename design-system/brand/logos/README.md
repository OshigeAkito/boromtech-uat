The seal, wordmark and lockup files. Each SVG has one ink written in, named in its file name: `orange` #e56e3f, `rust` #b4471d, `ink` #1a1b22, `light` #f2f1ee. Pick the file whose ink suits the ground (see The seal); never recolour with CSS filters. `favicon.svg` and `app-icon.svg` carry their own `night` #1e2235 square. The wordmark and lockups are outlined from Bricolage Grotesque ExtraBold, so they need no font to render.
