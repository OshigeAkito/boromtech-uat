# design-sync notes: BoromTech CI

- Synced to the Claude Design project "BoromTech CI": https://claude.ai/design/p/4f007695-41e9-47ae-8ba3-5e263ff1c322 (first sync 2026-10-19, 39 files, 5 components).
- Claude Design access: run /design-login in a standalone `claude` terminal. Running it from the desktop app's chat doesn't authorize the sync.
- The synced package is `@boromtech/brand` in `design-system/brand/` (not the job-board system in `design-system/components`). Scope chosen by the user on 2026-10-19: brand CI only, logo as React components plus tokens.
- Build: `node design-system/brand/build.mjs` regenerates `tokens.css` from `tokens.json`, bundles `src/` to `dist/` and emits `.d.ts`. `dist/` is gitignored, so always build before the converter.
- Converter flags: `--node-modules <repo root>/node_modules` (react, react-dom, typescript and esbuild live there, hoisted by the npm workspace) and `--entry ./design-system/brand/dist/index.js`. From a worktree, point `--node-modules` at the main checkout's `node_modules`.
- `cfg.tokensGlob` only works with `cfg.tokensPkg`; tokens ship through `cfg.cssEntry: tokens.css` instead, which also carries the Bricolage `@font-face` (extracted to `fonts/`) and the Google Fonts `@import` for Plex Sans Thai, Plex Sans, Plex Mono and Noto Sans SC.
- Render check runs without downloading Playwright's browser: install `playwright` with `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1` and set `DS_CHROMIUM_PATH="/Applications/Google Chrome.app/Contents/MacOS/Google Chrome"`.
- The wordmark outlines in `src/wordmark.ts` and `logos/*.svg` are generated by `node scripts/build-brand-logos.mjs` from the site's Bricolage Grotesque ExtraBold cut, with pen positions measured in Chrome (GPOS kerning). Rebuild them only if the font changes.
- All five cards use `cardMode: column` (they are wider than a grid cell).

## Known render warns

- `[FONT_REMOTE]` for IBM Plex Sans Thai, IBM Plex Sans, IBM Plex Mono, Hiragino Sans GB and Microsoft YaHei: expected. The Plex families come from the Google Fonts `@import`; the other two are system CJK fallbacks.

## Re-sync risks

- `tokens.json` values mirror `apps/website/src/styles/site.css`. If the website palette changes, update `tokens.json` by hand; nothing checks the two against each other.
- Plex fonts load from Google Fonts at runtime (network). Only Bricolage ships as a file.
- `src/wordmark.ts` hard-codes kerning measured once in Chrome; a different Bricolage build would need re-measuring (`XS` in `scripts/build-brand-logos.mjs`).
- `scripts/build-brand-logos.mjs` imports `fontkitten`, which is only present as a transitive dependency of Astro.
