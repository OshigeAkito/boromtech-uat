ก่อนเริ่มงาน

ไม่มีซอร์สโค้ดเลย ยังรีสโตร์ได้ไหม

ได้ในเคสส่วนใหญ่ เรารีคัฟเวอร์จากเซิร์ฟเวอร์โปรดักชันหรือไฟล์ที่ดีพลอยอยู่ หากรีคัฟเวอร์ไม่ได้ คุณจะรู้ตั้งแต่ในออดิตรีพอร์ต ก่อนจ่ายค่ารีสโตร์ใดๆ

การันตีครอบคลุมอะไรบ้าง

ทุกทาสก์ที่เราส่งมอบ การันตี 90 วัน หากปัญหาเกิดจากงานของเรา เราแก้ให้โดยไม่มีค่าใช้จ่าย ไม่รวมฟีเจอร์ใหม่ และส่วนที่มีผู้อื่นแก้ไขภายหลัง

ราคาคิดอย่างไร

ออดิตเป็นฟิกซ์ไพรซ์ ฿25,000 และหักคืนเต็มจำนวนเมื่อรีสโตร์ต่อกับเรา จากนั้นทุกทาสก์มีราคาของตัวเอง คุณเลือกลำดับได้เอง หากสโคปเปลี่ยน เราเสนอราคาใหม่ก่อนเริ่มเสมอ

รับเทคโนโลยีอะไรบ้าง

PHP, Laravel, WordPress, Java, .NET, Node.js, Python, React และ Angular บนดาต้าเบส MySQL, PostgreSQL, SQL Server และ Oracle ทั้งบนเซิร์ฟเวอร์ของคุณและบนคลาวด์ หากไม่อยู่ในรายการ ส่งมาให้เราดูก่อน

ข้อมูลของเราปลอดภัยไหม
