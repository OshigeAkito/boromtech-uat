## 8. ก่อนเริ่มงาน (คำถามที่พบบ่อย)

ข้อความชุดนี้ Google อ่านไปแสดงในผลค้นหาด้วย คำตอบควรตอบตรงคำถามในประโยคแรก

[faq.title] 📏 2–4 คำ
ก่อนเริ่มงาน

[faq.photoAlt]
แม่น้ำเจ้าพระยามองจากสะพานพระเจ้าตากสิน มีเรือลำเลียงสินค้าแล่นผ่าน

[faq.1.q] ไม่มีซอร์สโค้ดเลย ยังรีสโตร์ได้ไหม
[faq.1.a] ได้ในเคสส่วนใหญ่ เรารีคัฟเวอร์จากเซิร์ฟเวอร์โปรดักชันหรือไฟล์ที่ดีพลอยอยู่ หากรีคัฟเวอร์ไม่ได้ คุณจะรู้ตั้งแต่ในออดิตรีพอร์ต ก่อนจ่ายค่ารีสโตร์ใดๆ

[faq.2.q] การันตีครอบคลุมอะไรบ้าง
[faq.2.a] ⚠ ทุกทาสก์ที่เราส่งมอบ การันตี 90 วัน หากปัญหาเกิดจากงานของเรา เราแก้ให้โดยไม่มีค่าใช้จ่าย ไม่รวมฟีเจอร์ใหม่ และส่วนที่มีผู้อื่นแก้ไขภายหลัง

[faq.3.q] ราคาคิดอย่างไร
[faq.3.a] ⚠ ออดิตเป็นฟิกซ์ไพรซ์ ฿25,000 และหักคืนเต็มจำนวนเมื่อรีสโตร์ต่อกับเรา จากนั้นทุกทาสก์มีราคาของตัวเอง คุณเลือกลำดับได้เอง หากสโคปเปลี่ยน เราเสนอราคาใหม่ก่อนเริ่มเสมอ

[faq.4.q] รับเทคโนโลยีอะไรบ้าง
[faq.4.a] ⚠ PHP, Laravel, WordPress, Java, .NET, Node.js, Python, React และ Angular บนดาต้าเบส MySQL, PostgreSQL, SQL Server และ Oracle ทั้งบนเซิร์ฟเวอร์ของคุณและบนคลาวด์ หากไม่อยู่ในรายการ ส่งมาให้เราดูก่อน

[faq.5.q] ข้อมูลของเราปลอดภัยไหม
[faq.5.a] เราเซ็น NDA ก่อนเข้าถึงซิสเต็ม ใช้แอคเคาท์แยกที่คุณเพิกถอนได้ทุกเมื่อ และโค้ดกับด็อกคิวเมนต์ทั้งหมดเป็นของคุณ

[faq.6.q] เวนเดอร์เดิมยังอยู่ ทำงานร่วมกันได้ไหม
[faq.6.a] ได้ เราวางแผนแฮนด์โอเวอร์ร่วมกัน เพื่อให้ความรู้ไม่หายไประหว่างทาง
