# BoromTech

Main repository for BoromTech.

- `design-system/` holds the source for the BoromTech design system. `design-system/brand/` is the corporate identity and the merged system (`@boromtech/brand`: tokens, brand book, logo files and components, plus the job-board components); `design-system/components/` and `design-system/tokens.json` are the job-board source the job-board app imports. The browsable version is the BoromTech CI design system at https://claude.ai/artifact/YBDPtWLgzHbvzj9j5d6WAv, and Claude Design uses it from the "BoromTech CI" project at https://claude.ai/design/p/4f007695-41e9-47ae-8ba3-5e263ff1c322 (both private until shared; re-sync with `/design-sync`).
